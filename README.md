# Manos que hablan 🤟

Software educativo para aprender señas jugando.
Proyecto sociotecnológico Trayecto II, UPT de Aragua "Federico Brito Figueroa".

## Cómo está hecho
- **El juego:** aplicación web (HTML, CSS y JavaScript). Se instala en teléfono y computador, funciona sin internet y guarda el progreso en el aparato.
- **servidor_lsv.py:** programa en Python que ejecuta el juego en un servidor local.

## Jugar
https://aponteyilver93-stack.github.io/manos-que-hablan/

## Ejecutar con Python
1. Poner `index.html` y `servidor_lsv.py` en la misma carpeta.
2. Ejecutar `python servidor_lsv.py`.
3. Abrir http://localhost:8000

## Nota
Las descripciones de las señas son de referencia y deben ser validadas por un docente o intérprete de lengua de señas.
